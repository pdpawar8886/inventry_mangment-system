# 📦 Inventory Management System

The **Inventory Management System** is a simple and user-friendly web application designed to store, manage, and update product details easily.  
This project is useful for small shops, stores, or personal inventory tracking.

---

## 🚀 Project Summary

This system allows users to:
- Add new products  
- Edit existing products  
- Delete items  
- View product list  
- Track total quantity  
- Maintain clean and organized inventory data  

This project is built using **HTML, CSS, and JavaScript**.

---

## 🧩 Features

### ✔ Add New Items  
Add product name, quantity, and price.

### ✔ Edit Items  
Update product information without deleting.

### ✔ Delete Items  
Remove items easily from the inventory list.

### ✔ View Full List  
All items are displayed in a table format.

### ✔ Data Validation  
Prevents empty or incorrect inputs.

### ✔ Responsive Design  
Works on laptop and mobile screens.
